# 3477 simple skin - IF (티스토리 스킨)

`3477 simple skin v1.1`을 바탕으로, [if.odan.workers.dev](https://if.odan.workers.dev/)의 디자인과 기능을 티스토리 구조에 맞게 옮긴 스킨입니다.
홈 화면은 원래 스킨처럼 **프로필 + 티스토리 커버** 구성을 따르고, 나머지 페이지와 메뉴는 사이트 디자인을 따릅니다.

## 설치

1. `dist/3477-simple-skin-IF.zip`을 내려받습니다.
2. 티스토리 관리 › 꾸미기 › 스킨 변경 › **스킨 등록**에서 zip을 올리고 적용합니다.
   - 직접 올릴 때는 `skin.html`, `style.css`, `index.xml`, `preview.gif`는 그대로, `script.js`는 **파일 업로드**(= `images/script.js`)로 올려주세요.
3. 꾸미기 › 스킨 편집 › 홈 화면 설정에서 커버를 추가합니다.

## 사이트에서 옮겨온 디자인 · 기능

| 사이트 | 이 스킨 |
| --- | --- |
| 배경 이미지 + 흐림 + 배경색 덮기 | 스킨 옵션 `배경 이미지 (라이트/다크)`, `흐림`, `배경색 덮기` |
| 라이트 / 다크 테마, 색 팔레트 | 라이트·다크 색상을 각각 설정, 기본 모드(기기 설정/라이트/다크), 방문자 전환 허용 여부 |
| 브라우저 창 모양 프레임 (메뉴 · 뒤로 · 주소 복사 · 검색 · 테마) | 글·목록·방명록·태그 페이지에 적용 (옵션으로 끄기 가능) |
| 서랍 메뉴 (검색, 메뉴 타일, 아이콘·개수 있는 카테고리, 링크, 로그인, BGM) | 그대로 구현. 카테고리는 `[##_category_list_##]`를 스크립트로 다듬고, 아이콘은 `카테고리 아이콘` 옵션으로 지정 |
| BGM 카드 + 영상 펼치기(광고 건너뛰기) | 원래 스킨의 유튜브 BGM 6곡에 영상 펼치기 패널 추가 |
| 하단 플로팅 메뉴 | 5칸, 이름·주소·아이콘 설정. 주소에 `#search`를 넣으면 검색창이 열림 |
| 홈 타이틀 이미지 카드, 페어 프로필(두 아바타 + 심볼) | `홈 타이틀 이미지`, `두 번째 프로필 이미지` 옵션 |
| 위젯 카드 디자인 | 10종 커버를 위젯 카드 모양으로 |
| 달력 위젯 (월 이동, 일정 표시) | 캘린더 커버: 이번 달 달력 + 일정 목록. 제목에 `YYYY-MM-DD` 또는 매년 반복 `MM-DD` |
| 배너 위젯 (점 표시, 자동 넘김, 스와이프) | 배너 커버 |
| 목록 (리스트 / 갤러리 / 메모), 잠긴 글 표시 | 원래 스킨의 3종 목록을 사이트 디자인으로 |
| 글 화면, 반응 버튼, 이전/다음 글 카드, 같은 카테고리 글 | 티스토리 공감 버튼을 반응 버튼 모양으로 |
| 댓글 · 방명록 (비밀글) | `글 아래 댓글 영역 사용` 옵션 (사이트처럼 기본은 꺼짐) |
| 맨 위 / 맨 아래 버튼, 주소 복사 토스트, 페이지 진입 애니메이션 | 그대로 구현 |

## 티스토리 환경이라 달라진 점

- 사이트의 이모지 반응(❤️🥹😭✨👏)은 서버 저장이 필요해서, 티스토리 **공감** 버튼으로 대신했습니다.
- 조회수, 역극(RP) 전용 카드·말풍선 같은 사이트 고유 데이터는 티스토리에 없어 넣지 않았습니다.
- 사이트 홈의 좌우 스와이프 페이지 대신, 요청대로 원래 스킨의 세로 커버 구성을 유지했습니다.
